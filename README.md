🔐 Login Page Design

📌 Project Overview

This project is a simple and responsive Login Page created using HTML and CSS as part of my internship task.

The main objective of this project is to design a clean, user-friendly login interface that works on both desktop and mobile devices.

🎯 Features

- Email input field
- Password input field
- Submit button
- Clean and attractive user interface
- Responsive layout for mobile and desktop screens
- Simple and user-friendly design

🛠️ Technologies Used

- HTML5 – Used to create the structure of the login page.
- CSS3 – Used to style the page and improve its appearance.

📂 Project Structure

Login-Page-Design/
│
├── index.html
├── style.css
└── screenshot.png

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the "index.html" file.
4. Run it using a web browser to view the login page.
